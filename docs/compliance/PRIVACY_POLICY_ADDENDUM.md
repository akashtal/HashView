# Privacy Policy Addendum - Table Ordering

## Data Collection
When utilizing the HashView QR Ordering system, we collect:
- Customer Name
- Table Number
- Selected Menu Items
- IP Address (for rate limiting and fraud prevention)

## Data Usage
This data is used strictly for fulfilling the restaurant order. We do not sell this data to third parties.

## Data Subject Rights
Customers have the right to request an export of their order history, and the right to be forgotten. HashView provides an automated GDPR deletion endpoint that anonymizes the user's data.
